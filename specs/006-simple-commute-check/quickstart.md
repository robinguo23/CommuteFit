# Run and acceptance

在根目录bash start-local.sh；已有旧服务先在原终端Ctrl+C。首页为新初筛；/advanced保留详细工作检查，/journey保留独立路线。
输入DA18 4DE和SE18 6FL，默认60分钟和日间，提交后应看到进度、可取消按钮及一个最终主结论。默认不出现地图、availability表、行业模板或七张路线卡。
勾选早班/晚班时只检查所选类型；日间成功不跳过所选早晚。默认上午回程最多10:10；候选命中即停。高级详情才展示日期、最优路线和尝试时间。
精确时间选填，填写22:00–06:00应按次日回程；中文职位样例支持提取后确认多个班次，周期需确认第一周周一。
输入窗口时应约束参考时点，不形成假班表。无结果/服务失败应为待确认或带范围的未命中，不显示全时段不可能。
修改任一影响判断的输入，旧任务立即失效；旧返回不能覆盖新输入。取消后不继续轮询。

Verification:
- backend: ./mvnw verify（代理可用既有/tmp/commute-fit-m2离线缓存）
- frontend: npm test；npm run build
- 自动回归必须核对首日当天上午、次日早班复用前晚、第七晚的第八天节点、06:30按需复用、逐点停止和失败/未知汇总。
- 真实页面验收受运行环境限制时，明确记录，不把模拟用例当线上成功。
