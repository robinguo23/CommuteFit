## Automated normalization checks / 自动化归一化检查

`backend/src/test/resources/archived-journey-fares.json` contains 10 reduced examples derived from the raw archive. `FareAssessmentServiceTest` verifies that:

- each available route total is returned as GBP using the captured integer-pence representation;

- Hopper rows remain those returned by TfL, including zero-valued Hopper items where present;
- a route without a fare object remains `unable-to-confirm` with a null amount.
